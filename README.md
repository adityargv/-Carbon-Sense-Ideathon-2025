🌱 Carbon Sense

Making Daily Carbon Emissions Visible and Actionable

Ideathon 2025 | Team Brainy Bunch

📌 Project Overview

Carbon Sense is an ideathon project that proposes an automated and personalized system to help individuals understand and reduce their daily carbon footprint.

The idea focuses on making everyday carbon emissions visible through activity tracking, simplified carbon scoring, and personalized recommendations.

🚨 Problem Statement

People generate carbon emissions through everyday activities, but these emissions often remain invisible and untracked.

Without real-time information, individuals struggle to identify which activities contribute most to their carbon footprint. This makes it difficult to develop sustainable habits.

💡 Our Proposed Solution

Carbon Sense proposes a smart application that automatically tracks daily activities and provides understandable carbon emission estimates.

Key Features

Automatic Detection: Tracks mobility, purchases, and daily activities using phone data and activities.

Simplified Carbon Scoring: Converts collected activity data into an easy-to-understand carbon score.

Actionable Suggestions: Provides personalized tips for sustainable choices.

Positive Reinforcement: Encourages eco-friendly behaviour through rewards.

Real-Time Insights: Provides immediate awareness of carbon impact.

Data Privacy: Proposes keeping sensitive data on-device.

⚙️ How It Works

The application collects activity information through passive phone sensors.

It estimates carbon emissions associated with daily activities.

It generates a daily carbon score.

It highlights the major sources of emissions.

It provides personalized suggestions to reduce the carbon footprint.

🎯 Project Objective

To encourage environmentally responsible behaviour by making everyday carbon emissions easier to understand and reduce, without requiring drastic lifestyle changes.
